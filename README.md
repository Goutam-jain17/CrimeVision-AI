# CrimeVision-AI

AI-assisted digital evidence analysis system designed to support forensic image examination and crime investigation.

## Overview
CrimeVision-AI aims to help analyze digital evidence images using image processing and machine learning techniques.

## Features
- Digital evidence image analysis
- Backend API built with Python
- Frontend interface built with React and Vite
- Organized backend services and analysis routes

## Tech Stack
- **Frontend:** React.js, Vite, JavaScript, CSS
- **Backend:** Python
- **Tools:** Git, GitHub

## Project Structure
- `backend/` — Backend application, routes, services and analysis logic
- `frontend/` — Web application interface

## Getting Started
1. Clone this repository.
2. Follow the backend setup instructions in `backend/requirements.txt`.
3. Install frontend dependencies inside the `frontend` directory using `npm install`.
4. Follow the project's configuration instructions to run the application.

## Note
This project is intended to support digital evidence examination. Findings should be reviewed by qualified investigators; AI-generated results should not be treated as conclusive proof.
